Use the public join-request issue template in `cross-session-cooperation-protocol`.

## Measure
- first successful protocol message;
- first reply;
- elapsed time;
- failure points;
- help required;
- evidence-state understanding;
- reproducibility from a clean checkout.

Do not publish participant personal data as a success metric.
